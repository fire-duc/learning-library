툴팁 설명과 반드시 화면에 보여야 하는 중요 정보

툴팁은 보조 설명에 적합하지만 주요 위험과 현재 상태를 숨기는 장소로 쓰면 안 된다. 모바일에서는 마우스 올리기가 없다는 점도 고려해야 한다.

1. 개념을 연결해 이해하기

중지 여부, 주문 미확인, 데이터 지연과 실제·모의 모드는 기본 화면에서 확인 가능해야 한다. 지표 계산 설명이나 용어 뜻은 보조 설명으로 둘 수 있다.

2. 사례로 살펴보기

수익률 계산 방식은 도움말로 설명하되 비용 제외 성과라는 조건은 숫자 옆에 표시한다. 실거래 버튼 근처에는 현재 실행 모드를 직접 보여 준다.

3. 주의할 점과 확인 방법

툴팁에 내용이 있다는 사실과 사용자가 실제로 읽을 수 있다는 사실은 다르다. 키보드·터치 접근과 중요한 경고의 지속 표시를 확인한다.

글 끝의 확인 질문

사용자가 모르고 행동하면 결과가 달라지는 정보는 무엇인가?

글의 범위와 참고 자료

제공된 학습 주제를 바탕으로 작성한 개념 설명이다. 원본 프로젝트의 구현·수치·실행 결과를 확인한 보고서는 아니다. 사례는 실제 성과나 확정된 설정값을 뜻하지 않는다. 개념 연결과 사례는 이 학습 자료를 위해 작성한 설명·설계 제안이다. 실제 사업장 공정, 투자 판단, 제품 설정 및 서비스 공개 의무는 해당 조건의 자료로 별도 확인해야 한다.

학습을 위한 기록 · 자료의 범위와 출처는 각 글에서 확인하세요.
