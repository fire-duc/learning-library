화면 없는 로직 검사·장면 검사·실제 렌더 입력 검사의 역할과 한계

화면 없는 검사는 상태 계산을 빠르게 확인하고 장면 검사는 노드 연결과 자원 로딩을 확인한다. 실제 렌더 입력 검사는 보이는 대상과 조작이 맞는지 확인한다.

1. 개념을 연결해 이해하기

검증을 여러 층으로 나누면 실패 원인을 좁히기 쉽다. 계산 검사가 통과해도 카메라 가림이나 UI 클릭 전달 문제는 실제 화면에서 남을 수 있다.

2. 사례로 살펴보기

판매액 계산과 중복 지급은 로직 검사로, 누락 노드는 장면 로딩으로, 3D 부위 클릭은 실제 카메라·해상도로 확인한다.

3. 주의할 점과 확인 방법

headless 실행을 실제 사용자 경험의 증거로 쓰면 안 된다. 반대로 모든 계산 오류를 사람이 화면에서만 찾는 것도 비효율적이다. 변경 영향에 맞춰 조합한다.
