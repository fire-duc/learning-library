화면 좌표와 3D 광선 선택을 연결한 분해·배치 입력 처리

서론

화면에서 나사 위치를 눌렀다고 해서 컴퓨터가 곧바로 어떤 3D 물건인지 아는 것은 아니다. 화면의 점을 게임 세계의 방향과 연결하는 과정이 필요하다.

본론

1. 개념의 정의

화면 좌표

창 안에서 가로·세로 위치로 표현한 점이다. 같은 화면 좌표라도 카메라 위치와 방향이 바뀌면 다른 장소를 가리킨다.

광선 질의

특정 위치에서 한 방향으로 선을 뻗었을 때 어떤 충돌체와 만나는지 검사하는 방법이다. 빛을 실제로 그릴 필요는 없다.

충돌 계층과 마스크

충돌체를 종류별로 나누고 어떤 종류를 검사할지 고르는 장치다. 분해 부위와 배치 바닥을 구분하는 데 사용할 수 있다.

2. 개념을 연결해 이해하기

선택 가능한 충돌 계층, 최대 거리, 배치 표면을 제한하면 잘못된 대상을 줄일 수 있다. 화면 입력 수집과 물리 공간 질의 시점을 구분하는 것이 중요하다.

카메라에서 클릭 위치를 통과하는 방향을 구한 뒤, 그 방향에 있는 충돌체를 검사하면 후보를 얻는다. 그러나 후보가 선택 가능한 부위인지, 너무 멀지 않은지, 아직 외장에 가려져 있지 않은지는 별도 판단이다. UI 위의 클릭도 먼저 처리해 게임 세계로 같은 입력이 전달되지 않도록 해야 한다.

3. 사례로 살펴보기

부위 클릭은 부위 계층만 검사하고 바닥 배치는 배치 가능한 표면을 검사한다. UI 버튼 위의 클릭이 뒤쪽 물건까지 선택하지 않는지도 확인한다.

4. 주의점과 확인 방법

광선이 맞았다고 항상 상호작용할 수 있는 것은 아니다. 거리, 가림, 선행 분해 조건, 현재 카메라 모드를 추가로 검사해야 한다.

결론

클릭은 화면의 점이고 상호작용은 세계 안의 대상에 대한 행동이다. 광선 질의로 대상을 찾은 다음 게임 규칙으로 행동 가능 여부를 확인하는 두 단계를 구분하자.
