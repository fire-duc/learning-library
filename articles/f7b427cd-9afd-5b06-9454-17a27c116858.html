화면 좌표와 3D 광선 선택을 연결한 분해·배치 입력 처리

화면에서 클릭한 2D 위치는 카메라를 통해 3D 광선의 시작점과 방향으로 변환할 수 있다. 광선과 충돌체의 교차 결과로 선택 대상을 판단한다.

1. 개념을 연결해 이해하기

선택 가능한 충돌 계층, 최대 거리, 배치 표면을 제한하면 잘못된 대상을 줄일 수 있다. 화면 입력 수집과 물리 공간 질의 시점을 구분하는 것이 중요하다.

2. 사례로 살펴보기

부위 클릭은 부위 계층만 검사하고 바닥 배치는 배치 가능한 표면을 검사한다. UI 버튼 위의 클릭이 뒤쪽 물건까지 선택하지 않는지도 확인한다.

3. 주의할 점과 확인 방법

광선이 맞았다고 항상 상호작용할 수 있는 것은 아니다. 거리, 가림, 선행 분해 조건, 현재 카메라 모드를 추가로 검사해야 한다.
