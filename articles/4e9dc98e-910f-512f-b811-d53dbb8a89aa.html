로그인 기반 자동 복구와 전원·절전·인터넷 장애의 한계

로그인 시 실행은 사용자가 로그인하는 사건을 시작 조건으로 삼는다. 전원 꺼짐·로그인 전 상태·절전 중에도 지속 실행된다는 뜻은 아니다.

1. 개념을 연결해 이해하기

복구 조건을 프로세스, 운영체제 세션, 전원, 네트워크로 나눠 보면 적용 범위를 설명하기 쉽다. 복구 뒤에는 상태 확인과 주문 대사가 필요하다.

2. 사례로 살펴보기

로그인 뒤 워커가 자동 시작해도 인터넷이 끊겼다면 시세와 주문 확인은 실패할 수 있다. 네트워크 복구 후 미확인 주문을 대사한 뒤 재개 조건을 검사한다.

3. 주의할 점과 확인 방법

절전 복귀와 재부팅은 서로 다른 시험이다. 자동 복구가 사용자의 중지 상태를 덮어쓰지 않게 하고 실제 PC에서 각각 확인해야 한다.
