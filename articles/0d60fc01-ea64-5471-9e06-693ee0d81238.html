Windows 실행본 제작·배포 파일 구성·라이선스 포함·사용자 저장 보존

배포는 실행 파일 생성뿐 아니라 필요한 데이터, 사용 조건, 저장 위치와 업데이트 절차를 함께 제공하는 일이다.

1. 개념을 연결해 이해하기

Godot Windows 내보내기에는 실행 파일과 프로젝트 데이터가 필요하며 설정에 따라 배치가 달라진다. 엔진과 사용 자산의 라이선스는 각각 확인해야 한다.

2. 사례로 살펴보기

깨끗한 테스트 폴더에서 실행하고 새 저장을 만든 뒤 새 버전 배포 파일로 교체해 저장이 유지되는지 확인한다. 설치 폴더와 사용자 저장 위치는 구분한다.

3. 주의할 점과 확인 방법

개발 PC에서 실행됐다고 새 환경에서 검증된 것은 아니다. 자산 누락, 렌더러 호환성, 권한, 라이선스 안내와 기존 저장 호환성을 점검한다.

글 끝의 확인 질문

배포 파일 교체 때 삭제해도 되는 파일과 보존해야 하는 파일은 무엇인가?

글의 범위와 참고 자료

제공된 학습 주제를 바탕으로 작성한 개념 설명이다. 원본 프로젝트의 구현·수치·실행 결과를 확인한 보고서는 아니다. 사례는 실제 성과나 확정된 설정값을 뜻하지 않는다. 아래 자료는 관련 기술 동작의 참고 자료이며, 글의 설계 제안이나 사례 수치를 보장하는 근거는 아니다.
